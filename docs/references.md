## 视觉 / 个性 / craft 参考

### 01 · stillmakingstuff.com — Mauricio Daniachi
- **类型**：视觉 / 个性 / craft 参考（**非**结构参考）
- **喜欢它哪一点**：视线跟随鼠标的生命感；信息简约明确；简约但大胆；有趣、不死板
- **想偷师的具体东西**：
  ① 一个克制的**光标跟随**元素（做"活着、在回应你"的细节）
  ② 有声音的**微文案**（按钮/空状态/hover，用自己的语气）
  ③ **hover 小惊喜**
  ④ 第一屏**敢大敢空**、自信
- **不想要的部分**：艺术化 / 略隐藏的作品展示、沉浸式迷宫导航、满屏动效——不利于招聘者扫读
- **原则**：趣味放在**细节和微交互**，不放在**结构和导航**。

### 02 · leoparpeix.com — Léo Parpeix
- **类型**：视觉 / craft 参考（质感天花板）+ **作品行排版**结构参考
- **喜欢它哪一点**：整体质感；**2D 里融合 3D**（主效果方向）；电影感入场；作品行的高信息量元数据排版
- **想偷师的具体东西**：
  ① **首页 3D hero**（只首页做 3D）
  ② **滚动缩放转场**（下滑镜头推进）
  ③ **作品行排版**：大图 + 图下方静态元数据（编号 · 项目名(类型) · 年份 · 团队 · 角色）
  ④ 侧滑查看效果图；"Project link" → 改为"展开项目 / 进入详情"
  ⑤ 自定义光标、排版气场、滚动动效
- **实现路线（重要）**：**不照搬全站 WebGL**。走轻量路线——渲染图/形象合成 + **一个 Spline 签名**（Blender 出资产 → Spline 搭场景 + 绑滚动缩放 → 嵌入）。第 3 档全站 WebGL 是专职开发者干的，先不碰。
- **不想要的部分**：他是艺术总监，作品页偏体验、轻决策论证——**风格学他，案例的"决策优先 + 双速阅读"保留自己的**。

- **刹车提醒**：纯个性、零 case study；只做一个点；主线稳了再考虑

## case study 结构参考

### 03 · henningbirgersson.com/chime + /memoire — Henning Birgersson
- **类型**：case study **结构/内容**参考（骨）
- **为什么对口**：Umeå 交互设计 MFA、做软硬件交互；题材和我极近（chime = 传感器捕捉自然数据→存实体碟片→回味 ≈ Orbit；memoire = 纪念逝者、保存有故事的物件 ≈ Serava）
- **想偷师的具体东西**：
  ① **元数据块**：Type / Role / Team / Timeline / Keywords / Awards（扫读事实层）
  ② **编号解决方案流程**（3–4 拍讲完整个故事）→ 对应我 Orbit 记录→回味→延伸 / EchoCourt 捕捉→比对→反馈
  ③ **带 ①②③ 标注的细节分区**（硬件展示）
  ④ **独立的"问题/背景"段**（memoire 的 "How do we prepare for death?"）
  ⑤ **独立的"关键决策/挑战"段**（memoire 的 Participatory Approach / chime 的 Behind the Scenes）—— 最该学
- **要为我改良**：Henning 把决策/反思放最末尾；我要**决策更靠前**、决策密度更高（多写"为什么这么做、放弃了什么"）
- **用途**：内容骨架（五段）用它；页面**格式**用 BOC（见下）

## 格式参考（详情页版式）

### 04 · boc.studio/work/alien — BOC.Studio（Alien Audi）
- **类型**：详情页**版式/交互**参考（皮 · 容器形式）
- **喜欢它哪一点**：**左文右图 + 手风琴滚动联动**——右侧大图区放细节/原型/渲染，左侧文字分段（Context/Application/Process/Impact），滑到哪段图、左侧自动展开对应文字、其余折叠
- **想偷师的具体东西**：
  ① 左右分栏：左固定文字、右大面积可滑图
  ② 手风琴（同时只展开一段）+ 滚动联动（滑动驱动，非点击）
  ③ 标题下一行元数据（`AUTOMOTIVE · BOOST · 2025` → 我的 `App+硬件 · UX/交互 · 2025`）
- **注意**：它是代理商品牌活动展示，**只借版式，不借内容深度**；内容骨架用 Henning 的五段
- **刹车**：图文联动比上下滚复杂，移动端要退化成上下堆叠；Phase 4 交给 Claude Code 实现联动

## 逛完总结

- **视觉方向关键词**：极简 · 编辑感 · 大字排版 · 2D 融合 3D · 克制的趣味 · 有生命感
- **首页方向（已定）**：艺术化 3D 自我形象 hero + 滚动缩放转场；其余页干净；皮像 Léo，骨像自己
- **趣味原则（已定）**：放细节与微交互，不放结构与导航
- **确定不想要**：沉浸式迷宫导航、满屏动效、作品展示到"找不到/看不懂"的程度
