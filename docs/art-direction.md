## §1 气质定调 · Tone & Feel  ✅ 已定

### North Star（一句话总纲）
**冷静克制的编辑感底子 × 一个灵动、有生命感、略带技术巧思的签名交互。**

### 核心张力：90% 安静 × 10% 有生命感
整站以大面积冷静的编辑感托底（黑白灰、大留白、大字排版）；只在关键处——首页的 3D 形象——注入灵动与生命感。
反面教材两端都要避免：**全程炫酷**（躁、廉价、拖性能）与**全程性冷淡**（无聊、没记忆点）。
要的是：稳得住的克制 + 敢在一处下狠手。

### 气质关键词
极简 · 编辑感 · 偏冷的中性（理性但留一丝温度，非纯科技冷）· 大字排版 · 2D 融合 3D · 有生命感 · 克制的趣味。

### 签名交互（已定方向）
> **签名交互** = 一个网站独一无二、最让人记住的交互动作，像签名一样代表这个站（如 stillmakingstuff 的"视线跟随鼠标"）。

- **本站唯一签名 = 3D 自我形象对鼠标有反应**（跟随光标 / 看你 / 微动，具体动法 §4 定）。
- **原则：宁精勿多。** 只做这一个签名，精雕；不叠加多个鼠标特效（水波 + 生物跟随 + …）——堆多个 = 廉价炫技，反而拉低高级感、伤加载与移动端。
- 它不是额外堆一层特效，而是让本就要做的 3D hero 形象"活过来"——**签名交互与 hero 形象合并为同一件事**（有生命感 + 秀技术 + 克制统一，一举三得）。

### 3D 融入整站的两条硬约束
1. **形象的材质 / 配色不自成一派**：用整站偏冷的中性色 + 项目 accent。倾向**冷调单色雕塑感、哑光、微妙光泽**，而非花哨卡通。
2. **平面部分要"够 3D 友好"**：留白、深度、光影、层次贯穿平面设计，让 3D 出现时是"长出来的"而非"贴上去的"。

### 不要什么（边界）
- 多个鼠标特效叠加 / 廉价炫技。
- 纯性冷淡、无记忆点。
- 可爱幼态（与"偏冷"定位冲突）。
- 伤加载 / 移动端的重特效。
- 皮盖过骨：任何视觉/动效都不能损害招聘者对作品与决策的扫读。

## §2 字体系统 · Typography  ✅ 已定

### 字体组合（方案 B · 全部开源免费，Google Fonts 可引）
| 角色 | 字体 | 用途 |
|---|---|---|
| **Display** | **Archivo Expanded** | hero 名字、案例大标题、区块标题 |
| **正文** | **Inter** | 段落、简介文字 |
| **元数据 / 标签** | **Space Mono** | 编号、年份、角色、`App+硬件·UX/交互·2025` 等技术标签 |
| **中文（全部）** | **思源黑体 Noto Sans SC** | 所有中文，呼应 Orbit 自有设计规范 |

> 西文与中文分开选：西文字体基本不含好用的中文字形，故中文统一走思源黑体。

### 字号层级（type scale）
**依据模块化比例 = 1.25（major third）**：相邻层级按 ×1.25 递增，保证节奏统一（现代设计系统通用做法）。
**具体 px 值待 Phase 4 用 `clamp()` 落地**（响应式动态缩放，非死数字）；此处只定层级关系与字重。

| 层级 | 字体 / 字重 | 用途 | 相对大小 |
|---|---|---|---|
| Display XL | Archivo Expanded 800 | hero "LIU YUMO" | 超大（首屏视觉焦点） |
| Display L | Archivo Expanded 700 | 案例页大标题 | 很大 |
| H2 | Archivo Expanded 600 | 区块标题 | 大 |
| 正文强调 | Inter 500 | 决策要点、关键句 | 舒适阅读 + 略重 |
| 正文 | Inter 400 | 段落 | 舒适阅读尺寸 |
| 元数据 | Space Mono 400 | 编号/年份/角色/标签 | 小、字距略宽、大写 |
| 中文标题 | 思源黑体 700 / 900 | 中文大标题（刘予墨等） | 配合对应英文层级 |
| 中文正文 | 思源黑体 400 | 中文段落 | 舒适阅读 |

### 规范依据（每条都有据）
- **有限层级**：用固定 type scale 而非随手写字号——一致性与节奏的基础（Material / Apple HIG 等通用要求）。
- **模块化比例 1.25**：层级间按固定比例递增，避免大小混乱；1.25 适中，标题与正文拉得开但不夸张。
- **正文可读性**：正文目标 16–18px、行高 1.5–1.6、每行英文 45–75 字符（落地时遵守）。
- **展示字体只用于标题**：Archivo Expanded 是展示体，可读性不适合长正文/小字，故正文交给 Inter、元数据交给 Space Mono——这是刻意的分工。
- **对比度**：正文与背景 ≥ 4.5:1（WCAG AA）——在 §3 配色中正式验算。

### 待 Phase 4 落地时补严
- 各层级的具体 px 值 + `clamp()` 响应式区间。
- 逐档字重的最终确认（当前 800/700/600/400/500 为方向）。
- 行高、字距、每行字符数的精确值。

> 全部为 CSS 变量（token）实现，改一个值全站生效。
## §3 配色系统 · Color  ✅ 已定

### 核心决定
1. **无项目 accent**：全站（含三个案例页）用**同一套靛蓝中性色**，不给项目单独配色——让产品图自己发光（EchoCourt 渲染的紫、Serava 黑白、Orbit 光谱 UI 本就在图里）。更统一、不花。
2. **靛蓝为主调**：黑换成深靛蓝，所有灰往蓝偏。靛蓝是全站性格色。
3. **深/浅双模式**：浅色为主体页面，深靛蓝用于 hero 与大色块（最能衬托发光的 3D 形象与签名交互）。
4. **一个统一高亮蓝**：链接 / hover / 当前状态 / 签名交互的功能色（非项目 accent）。

### 浅色模式（主体页面）
| Token | 值 | 用途 | 对比度(vs paper) |
|---|---|---|---|
| `--paper` | `#ECEDF2` | 背景（带蓝味浅灰） | — |
| `--paper-2` | `#F6F7FB` | 卡片 / 浅表面 | — |
| `--ink` | `#141A2E` | 主文字（深靛蓝近黑） | 14.76:1 ✓AA |
| `--ink-2` | `#3E4665` | 次要文字 | 7.92:1 ✓AA |
| `--faint` | `#5D6688` | 元数据 / 最弱 | 4.83:1 ✓AA |
| `--line` | `#D2D5E2` | 分隔线 | — |

### 深色模式（hero / 大色块）
| Token | 值 | 用途 | 对比度(vs deep) |
|---|---|---|---|
| `--deep` | `#081160` | **最深主色**（高纯靛蓝，hero 底） | — |
| `--deep-2` | `#161E42` | 深色次表面 | — |
| `--on-deep` | `#EEF0F8` | 深底主文字 | 14.65:1 ✓AA |
| `--on-deep-2` | `#9AA3C4` | 深底次要文字 | 7.24:1 ✓AA |

### 高亮蓝（统一功能色）
| Token | 值 | 用途 | 对比度 |
|---|---|---|---|
| `--hi` | `#4C6FFF` | 浅底上的链接/hover/交互 | 3.57:1（大字/按钮/图标✓；小字链接需加深或加粗） |
| `--hi-on-deep` | `#6E8BFF` | 深底上的高亮 | 5.85:1 ✓AA |

### 3D 形象取色约束（呼应 §1）
- 形象用靛蓝中性体系：**冷调单色雕塑感、哑光、微妙光泽**，非花哨卡通。
- 置于 `--deep` 深靛蓝底之上，靠光/材质出彩，与整站同一套色语言。

### 规范依据
- **对比度**：正文相关色全部 ≥ 4.5:1（WCAG AA）；高亮蓝浅底 3.57:1 仅用于大字/按钮/图标，小字链接落地时加深或加粗补足。
- **克制**：去 accent + 单一主调，符合"90% 安静"定调；颜色的记忆点集中在靛蓝主色与产品图。
- 全部为 CSS 变量（token），改一个值全站生效。

### 待 Phase 4 落地
- 深/浅模式的具体切换范围（哪些区块深、哪些浅）。
- 高亮蓝小字链接的加深变体。
- 深靛蓝底上 3D 形象的光效参数。

## §5 间距 / 圆角 / 动效语言  ✅ 已定

### 间距系统 · 8pt 网格
- 所有间距用 **8 的倍数**：4 / 8 / 16 / 24 / 32 / 48 / 64 / 96 …
- **依据**：8pt 网格是业界通用标准，节奏统一、对齐干净，主流 design system 通用。

### 圆角 · 克制
- 卡片 / 大色块：小圆角 **8–12px**；按钮：中圆角；图片：近直角或极小圆角。
- **不用大圆角**（会显软、偏消费品，与冷静编辑感 + 靛蓝克制不符）。

### 动效语言（决定高级 vs 廉价）
- **缓动**：自然缓动曲线（ease-out 类），不用生硬 linear。
- **时长**：微交互快 **150–250ms**；页面级转场稍慢 **400–600ms**；不拖沓。
- **克制**：呼应 §1"90% 安静"——动效只用在有意义处（hover、转场、签名交互），不满屏乱动。
- **签名交互例外**：3D 形象跟随鼠标是全站动效焦点，可更"活"。
- **无障碍**：全站尊重 `prefers-reduced-motion`，关动效时退化为无动画。

### 阴影 / 层次 · 偏冷克制
- 用**极淡阴影**或**分隔线 / 色块**区分层次，不用重投影（重阴影显廉价）。
- 深色模式靠明度差 + 微光做层次。

### 规范依据
- 8pt 网格、有节制的圆角、克制而有意义的动效、尊重 reduced-motion——均为现代网页设计通用最佳实践。
- 全部为 CSS 变量（token）实现，改一处全站生效。
