# 首页信息架构 · IA — Homepage

> Phase 2 产物。只定**结构与顺序**，不含视觉（配色/字体/动效细节留到 Phase 3）。
> 原则来自 `strategy.md`：招聘者优先、扫读层在前、深读层（详情页）在后。

## 首页整体：一条竖向流，分四区

体验上像"一屏一屏翻过去"（有 3D 缩放转场、导航可直达），底层是同一页的锚点滚动。

```

│ 区①  HERO                                          │
```

## 逐区说明

### 区① HERO
- 主体：你的**艺术化 3D 自我形象**（Blender 出资产 → Spline 搭场景与交互 → 嵌入）。
- 文字极简：名字 + 一句定位 + SCROLL 提示。
- 交互：**下滑触发 3D 缩放转场**（镜头推进 / 形象缩放），把「入场」平滑带入「简介」。
- 护栏（Phase 3 实现时）：移动端退化为静态图 · 首屏懒加载 · 尊重 prefers-reduced-motion。

### 区② 简介（= About）
- 内容：你是谁 · 方向 · 能力，文字为主，带**一点点击互动**（呼应个性、不喧宾夺主）。
- **必含**：联系方式 + 简历下载入口（招聘者要找得到）。
- 导航 **About 直接跳到这里**——不再单独做 About 页。
- 区尾一行 eyebrow：`SELECTED WORK — 3 PROJECTS · 2025`，标出作品开始（**一行，不占整屏**）。

### 区③ 作品（Léo 式）
每个作品一个单元，结构一致：
- **大图 / 效果图**，图片**左右两侧各一个滑动按钮**，切换查看多张效果图。
- **单击大图 → 进入该项目详情页**（唯一的进入方式）。
- 图片**下方静态排列**（非悬停浮出）：
  - 一句话简介（**建议带一个"关键决策"钩子**，让扫读层就有决策信号）
  - 你的角色
  - 元数据：项目名（类型）· 年份 · 团队 / Solo ·（可选）标签
- 顺序：`01 Orbit 时环` → `02 EchoCourt 回声球场` → `03 Serava 喵梦`

### 区④ FOOTER
- 联系 / 邮箱 / 简历 / 社交链接 / 回顶部。

## 导航规则

| 导航项 | 行为 |
|---|---|
| Work | 跳到区③（作品区起点） |
| About | 跳到区②（简介） |
| Contact | 跳到区④ / 唤起联系方式 |
| CN / EN | 中英切换 |

- **不需要**页面内一整屏的"作品章节封面"。三个作品，越快看到越好。
- 简介↔作品之间只用**一行 eyebrow** 做分隔标识。

---

## 双速阅读落点（对齐 strategy）

- **扫读层 = 首页**：hero 立身份 → 简介说能力 → 作品行（图 + 一句话决策钩子 + 角色 + 元数据）。招聘者不点进详情也能判断。
- **深读层 = 项目详情页**：完整论证（问题→角色→关键决策与取舍→结果→反思）。给愿意深读的招聘者与导师。

---

## 皮与骨（对齐参考）

- **皮可以像 Léo / studio 参考**：3D hero、缩放转场、极简、作品行排版、侧滑效果图、克制的趣味。
- **骨必须像你自己**：作品行的"角色 + 一句话决策钩子"不能省；详情页保留决策优先 + 双速阅读。
