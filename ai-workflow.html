Methodology / AIGC

AI Creative Workflow

AI 创作工作流

Human-in-the-loop · 人机协作方法论

从设计目标出发，通过生成、评估、诊断与反馈循环，将 AI 输出逐步收敛为可落地的设计结果。

  • AI Workflow
  • Human-in-the-loop
  • AI Evaluation
  • Design Process

  1. 01 / Define

    目标定义 Define

    明确任务与视觉目标

    • 设计需求
    • 使用场景
    • 风格方向
    • 参考素材

  2. 02 / Generate

    AI 生成 Generate

    建立初始方案空间

    • Prompt
    • Reference
    • 参数控制
    • 多方案生成

Human-in-the-loop

评价 → 诊断 → 迭代

  1. 03 / Evaluate

    结果评估 Evaluate

    判断生成结果的有效性

    • 基础质量
    • 视觉质量
    • 风格一致性
    • 任务匹配度

  2. 04 / Diagnose

    问题诊断 Diagnose

    定位 Bad Case 的来源

    • Prompt 问题
    • 参考素材问题
    • 参数设置问题
    • 模型能力边界

  3. 05 / Refine

    迭代优化 Refine

    将判断转化为具体操作

    • 调整 Prompt
    • 更换参考
    • 参数优化
    • 局部修改 / 人工调整
05 → 03 · 迭代后重新评价

06 / Deliver

设计落地 Deliver

进入真实设计场景

  • 视觉设计
  • 3D 资产
  • UI / 交互
  • AR / 原型

“AI 扩展可能性，设计判断负责让结果收敛。”

生成不是终点，评价—反馈—迭代才构成完整的 AI 创作工作流。
